Deskripsi Proyek: MBG Report App
--------------------------------

Ringkasan:
MBG Report App adalah aplikasi web untuk pemantauan program Makan Bergizi Gratis (MBG),
memfasilitasi input menu harian, data gizi, pengaduan, dan pengelolaan tim SPPG.

Teknologi:
- Backend: PHP (MySQLi)
- Frontend: HTML/CSS/JavaScript

Struktur & Peran Utama:
- Folder `pages/`, `process/`, `assets/`, `api/` menyimpan halaman, handler server, aset dan endpoint API.
- Role: `Admin`, `Petugas Gizi`, `Petugas Pengaduan` dengan hak akses berbeda.

Fitur Penting (ringkas):
- Role-based UI & server enforcement (Admin read-only di beberapa area; Petugas Gizi/Pengaduan punya aksi khusus).
- Modal image/detail untuk menu (AJAX fetch), form pengaduan dengan submit AJAX, responsive navbar.
- Validasi unik ID pada proses tambah/edit (sekolah, user, sppg) untuk mencegah duplikasi.

Catatan Terakhir:
- Footer halaman publik telah diseragamkan mengikuti `index.php` (contact, maps, agencies).
- Script modal kini me-reset status saat halaman dimuat untuk mencegah overlay/overflow persisten.

Deskripsi Skrip JavaScript (assets/js)
-------------------------------------

1) `complaint-form.js`
- Fungsi: Menangani submit form pengaduan via AJAX, mengirim data ke `process/pengaduan/pengaduan_add_process.php`, mem-parse respons JSON, menampilkan alert di elemen `alert-container`, dan mereset form jika berhasil.
- Digunakan oleh: `index.php` (form pengaduan publik).
- Ketergantungan DOM: elemen dengan `id="complaint-form"` dan `id="alert-container"`.

2) `menu-detail-modal.js`
- Fungsi: Mem-fetch detail menu via `api/menu_detail.php?id=...`, mengisi isi modal (gambar, nama, tanggal, sekolah, data gizi), menampilkan modal `#menuModal` (dan menonaktifkan scroll body), serta menutup modal dan mereset status saat halaman dimuat.
- Digunakan oleh: `pages/petugas/menu/menu_manage.php`, `pages/petugas/menu/menu_history.php` (dipanggil saat klik tombol "Detail").
- Ketergantungan DOM: `#menuModal`, `#menuDetailImage`, `#menuDetailName`, `#menuDetailDate`, `#menuDetailSchool`, `#menuDetailKalori`, dsb.

3) `modal.js`
- Fungsi: Modal gambar umum — `openModal(imageSrc, imageName)` / `closeModal()` untuk menampilkan preview gambar, mengisi `#modalImage` dan `#caption`, mengatur body overflow, dan menutup saat klik luar atau Escape. Menyertakan inisialisasi untuk mereset semua modal pada `DOMContentLoaded`.
- Digunakan oleh: `pages/sppg/sppg_manage.php` (preview gambar) dan halaman lain yang memerlukan preview gambar modal.
- Ketergantungan DOM: `#imageModal`, `#modalImage`, `#caption`.

4) `navbar.js`
- Fungsi: Menangani toggle navbar responsif — toggle class `active` pada `#navbar-toggle` dan `#navbar-menu`, menutup menu saat link diklik atau saat klik di luar elemen.
- Digunakan oleh: `index.php` dan halaman front-end yang memuat navbar (mis. beberapa halaman publik/FE seperti `pages/menu_history.php`).
- Ketergantungan DOM: `#navbar-toggle`, `#navbar-menu`, struktur link di dalam menu.

Catatan integrasi & potensi masalah:
- Semua skrip bergantung pada keberadaan elemen DOM tertentu; jika elemen tidak ada, event listener dapat gagal — pastikan halaman hanya menyertakan skrip yang relevan atau menambahkan pengecekan keberadaan elemen (sudah sebagian ditangani).
- Beberapa skrip (modal) mengubah `document.body.style.overflow`; inisialisasi pada `DOMContentLoaded` ditambahkan untuk mereset ini dan mencegah overlay/scroll terblokir saat ganti role atau pindah halaman.
