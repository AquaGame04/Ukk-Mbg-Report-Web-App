# 🚀 QUICK REFERENCE - MBG REPORT FLOWCHART

**Panduan Cepat untuk Menggunakan Flowchart**

---

## 📥 IMPORT FLOWCHART KE DRAW.IO - 3 LANGKAH CEPAT

### Langkah 1: Buka Draw.io
```
Kunjungi: https://app.diagrams.net/
(Atau buka aplikasi desktop Draw.io)
```

### Langkah 2: Import File
```
File → Open From → Device
Pilih salah satu file XML:
  • flowchart_user.xml
  • flowchart_admin.xml
  • flowchart_petugas_gizi.xml
  • flowchart_petugas_pengaduan.xml
```

### Langkah 3: Selesai!
```
Flowchart siap diedit dan diexport
```

---

## 📊 4 FLOWCHART TERSEDIA

### 1. USER (Publik)
- Akses tanpa login
- 5 menu: Menu hari ini, Riwayat, SPPG, Pengaduan buat, Pengaduan lihat
- File: `flowchart_user.xml`

### 2. ADMIN
- Akses penuh ke semua fitur
- 5 menu: User, Sekolah, SPPG, Menu Gizi, Pengaduan
- File: `flowchart_admin.xml`

### 3. PETUGAS GIZI
- Input data nutrisi
- 4 menu: Input sekolah, Menu harian, Data gizi, Riwayat
- File: `flowchart_petugas_gizi.xml`

### 4. PETUGAS PENGADUAN
- Kelola laporan
- Proses: Lihat list → Filter status → View detail → Update status → Add notes → Save
- File: `flowchart_petugas_pengaduan.xml`

## 💾 EXPORT FLOWCHART

Dari Draw.io:
```
File → Export As:

PNG/JPG      = Untuk presentasi & cetak
SVG          = Untuk web & responsive
PDF          = Untuk dokumentasi formal
XML          = Untuk edit/backup
```

## ❓ TROUBLESHOOTING CEPAT

| Masalah | Solusi |
|---------|--------|
| File tidak terbuka | Cek file tidak corrupt, download ulang |
| Tampilan berantakan | Klik "Fit Page" di menu Draw.io |
| Ingin edit warna | Double-click elemen, pilih warna di panel kanan |
| Ingin print | Export ke PDF, lalu print dari PDF reader |
| Mau share ke team | Export PNG + upload ke Drive/Teams |
